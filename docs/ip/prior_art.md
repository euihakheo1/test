# 선행문헌 비교표 (작성 중)

이 문서는 연구·특허 검토를 위한 **작업 기록**이다. 신규성·진보성·침해 여부 같은 법적 결론을 쓰지
않는다. 각 칸은 "문헌에 적힌 내용"과 "제때받기 구현에 있는 내용"을 나란히 적고, 차이는
"확인할 차이"로만 적는다. 문헌 원문을 읽지 않은 칸은 비워 두고 "미확인"이라고 쓴다.

## 다음 작업

1. 세 문헌 원문 확보(위 경로), 서지사항 기록.
2. 각 문헌의 독립항을 구성요소로 나누어 A~H 축에 대응시키고 "문헌에 적힌 내용"만 인용(짧게, 출처 쪽수).
3. "확인할 차이" 열을 문헌 기준으로 갱신. 판단은 변리사 검토 몫으로 남긴다.
4. 추가 선행문헌 검색어 후보: reconciliation payment invoice allocation ambiguity; dependency graph
   invalidation query scope; approval bound to result hash; 정산 대사 지연이자 자동 계산.
