# E2E 고정 입력 (테스트 전용)

손으로 쓴 두 줄짜리 CSV 입니다. 화면 → API → worker 흐름이 끝까지 이어지는지만 확인하며, 평가 데이터나
실제 거래 자료가 아닙니다. 평가 결과(`docs/eval_results.md`)에 쓰지 않습니다.

| 파일 | 쓰임 |
|---|---|
| `settlement_v1.csv` | 머리글을 알아보지 못하는 정산서(열 매핑 확인 단계를 거치게 함). 상품수령일 열이 없어 지급기한 계산은 보류되고 필요 서류가 안내됨 |
| `settlement_v2.csv` | 같은 문서의 정정본(거래 형태만 직매입 → 특약매입). 승인된 결과가 `REVIEW_REQUIRED` 로 바뀌는지 확인. 금액·참조번호·기준일은 행 식별 키에 들어가므로(`ingest/formats/settle.py` `key_fields`) 이를 바꾸면 같은 결과의 재확인이 아니라 새 결과(이전 결과는 대체됨)가 된다 |
